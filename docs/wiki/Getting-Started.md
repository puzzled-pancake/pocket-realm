# Getting Started

This is the normal first-time path. The exact preparation time depends on the device, storage speed, and the size of the selected client folder.

## Before you begin

You need:

- An Android device with enough free internal storage.
- A complete World of Warcraft 1.12.1 build 5875 client folder that you are
  entitled to use. It must be a plain, already-extracted (uncompressed)
  folder — the one that directly contains `WoW.exe` and a `Data` folder — not
  an installer, downloader/launcher, or `.zip`/`.7z`/`.rar` archive. Pocket
  Realm cannot run installers or open archives; extract a compressed copy
  first, then select the extracted folder itself.
- A charger for the first import and long setup work.
- Touch access for folder selection, login fields, and character creation.
- A controller, keyboard and mouse, or the on-screen control layout for play.

## 1. Import the game files

A first-run tutorial opens on a fresh install and walks through this step;
its final button lands on the import screen with the folder picker already
open. You can replay it anytime from **Settings → Setup → Show first-run
setup guide**.

Open **Settings**, scroll to **Setup**, and choose **Game files and import**. Select the client folder when Android opens the folder picker: the extracted client itself (directly containing `WoW.exe` and `Data`), never an installer, launcher, or archive.

Pocket Realm treats the selected folder as read-only. It copies and verifies the required files into private app storage. The original folder is not used as the live game folder.

The import screen shows:

- The current phase.
- The number of files processed.
- The amount copied and verified.
- The current file.
- Any server-data preparation stage.
- Whether background import work is still active.

If Android interrupts the work, return to the same screen and use **Resume** when it is available.

## 2. Choose a basic setup

The default choices are meant to work without deep technical knowledge. Before the first launch, it is still useful to check:

- **Display** for 1280 x 720 performance or 1920 x 1080 sharpness.
- **World population** for the number of computer-controlled residents.
- **Controls** for the correct input device and layout.
- **Sound** if game audio should be on.

The default population is Alive Realm, 320 bots. Presets up to Crowded 400 run fine on the development handheld (a Retroid Pocket 6), so pick the world size that sounds good and try them out. Quiet 25 remains the lightest choice for battery life.

## 3. Start the realm

On Home, choose **Start realm**. Wait until the status changes from Starting to Realm online.

Starting the realm before the game is useful on the first run because it allows the app to create and verify a local account.

## 4. Create a local account

Enter an account name and password in the **Local account** card. Leave the account type set to **Player** for normal play. Administrator accounts are intended for local maintenance and have extra permissions.

Choose **Create & remember**. Pocket Realm verifies the account through the running local world and saves it for optional automatic login.

## 5. Open the game

After the local account is ready, start the game from Home. On later runs, **Realm + game** can start both parts together when the app has everything it needs.

Use touch for the original login and character creation screens when needed. Once in the world, use the selected controller or touch layout.

## 6. Finish safely

Return to the Pocket Realm launcher and use its save and exit action. This lets the app close the client, finish durable world writes, and stop the local services in order.

Do not rely on the desktop-era game Quit button as the main way to close the complete Pocket Realm session.

## A good first setup

For a simple first test on a Retroid Pocket 6:

1. Use the Performance display option.
2. Keep the default Alive Realm population (320 bots), or try any preset up to Crowded 400.
3. Use Built-in leveling controls without an add-on.
4. Keep the on-screen controls visible until the physical controls feel familiar.
5. Leave LAN play off.
6. Create a normal Player account.
7. Enter the world and test movement, camera, targeting, jump, and one ability.
8. Save and exit through the launcher.
