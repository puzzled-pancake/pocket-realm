# Pocket Realm Wiki

Pocket Realm is an Android launcher and local game environment for playing a user-supplied World of Warcraft 1.12.1 client on a handheld device. It brings the game client, a private realm, local player accounts, computer-controlled residents, controller support, touch controls, add-ons, backups, and troubleshooting into one app.

This wiki describes the project as it exists now. It is written for players, testers, family members, and other readers who do not need to understand the code.

> Pocket Realm is still being developed. Screens and wording may change. The wiki records the current result, not a promise that every planned feature is finished.

## A quick description

Pocket Realm turns one Android handheld into both the game machine and the local server. The player supplies a supported game client. Pocket Realm makes a private working copy, starts the local world, manages a local account, opens the game, and closes everything in a safe order when the player finishes.

The normal experience is offline. An optional experimental LAN mode can let another device join a host on the same private network. It does not turn the local realm into a public Internet server.
